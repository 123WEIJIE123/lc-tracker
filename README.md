# 力扣高频20题 · 三刷打卡器

本地单文件刷题打卡工具，**双击 `index.html` 即可使用**，无需安装任何依赖。

## 功能

- 📋 **每日打卡** — 按「2旧题 + 2新题 + 1薄弱」公式记录，自动联动三刷进度
- 📊 **三刷追踪** — 20题分三级优先级，每道题记录3次刷题日期，点击题号直达力扣网页
- 📈 **进度统计** — 环形图、热力图、薄弱项分析
- 💾 **数据导出/导入** — JSON 格式备份，换电脑也能继续

## 使用方法

1. 下载 `index.html`
2. 双击用浏览器打开
3. 数据自动保存在浏览器本地存储（localStorage）
4. 建议每周导出一次 JSON 备份

| 🟡 第二优先级 | 5 | 94 中序遍历、104 最大深度、226 翻转二叉树、236 最近公共祖先、21 合并有序链表 |
| 🔵 第三优先级 | 9 | 1 两数之和、215 第K个最大、3 无重复子串、56 合并区间、198 打家劫舍、155 最小栈、141 环形链表、42 接雨水、22 括号生成 |

## 技术

纯 HTML/CSS/JS 单文件，零依赖。数据存储在浏览器 localStorage。
